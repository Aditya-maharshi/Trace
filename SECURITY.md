# Security Policy

## Supported Versions

Currently, only the `main` branch deployed to the production environment is supported with security updates.

## Reporting a Vulnerability

We take the security of Trace seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to our security team via email at:
**security@example.com**

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible depending on complexity.

### What to include in your report:
- Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

This project is intended for government and commercial compliance use. Any disclosure of live vulnerabilities must be coordinated.
